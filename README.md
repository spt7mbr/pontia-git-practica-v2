# Práctica de Git y GitHub - PontIA

Este repositorio contiene los ejercicios prácticos del módulo de control de versiones del Máster de Inteligencia Artificial y Cloud Computing de PontIA.

## Objetivos

- Crear y configurar un repositorio Git.
- Proteger la rama principal main.
- Utilizar el archivo .gitignore.
- Trabajar con ramas y Pull Requests.
- Resolver conflictos de merge.
- Automatizar tareas mediante GitHub Actions.
